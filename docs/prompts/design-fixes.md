Архитектура и правила:
• Сначала токены: добавь их в `colors.css` (или новый `tokens.css`, подключённый в `index.css`), затем используй их в страницах. Хардкод цветов, размеров и отступов в стилях страниц не добавлять.
• Mobile-first. Брейкпоинты: 480 / 768 / 1024 / 1280px, контейнер `max-width: 1200px` с боковым gutter 16px (на мобильном) — 32px (от 1024px).
• Не использовать `100vw` для ширины блоков и отрицательные margin, которые выводят контент за пределы контейнера. Декоративные листья (`leaf1…leaf4`) — `position: absolute` внутри контейнера с `overflow: clip`. На мобильном скрыть или уменьшить их, чтобы они не перекрывали текст.
• Новые `!important` не добавлять. Существующие убрать там, где это возможно без побочных эффектов.
• Разметку менять минимально и семантично. Тексты, SEO-заголовки, alt и `PageSeo` не менять, кроме обёрток для акцентов.
• Работай в 3 этапа. После каждого этапа: `npm --prefix frontend run build` без ошибок, проверка в браузере на 375, 768 и 1440px, отдельный коммит с понятным сообщением на русском.

Функционал — что исправить:

ЭТАП 1. Критичное

Страховка — `overflow-x: clip` на корневом контейнере страницы и `img { max-width: 100%; height: auto; }`. 2. Главный экран на мобильном. H1 налезает на фото с чайником и подзаголовок, а верх закрыт шапкой. Нужно: до 768px одна колонка, сначала текст, потом фото, без наложений. 3. Шапка на мобильном: логотип, бургер и корзина сейчас в огромных кругах и занимают около 15% экрана. Иконки сделать 40–44px, высоту шапки — не больше 64px на мобильном и 76px на десктопе.
4. Контраст и шрифты — применить правила из раздела «Дизайн»: Jost вместо Princess Diana в H1/H2, `--color-cta-text` для оранжевых заголовков, основной текст без прозрачности, тёмный текст на оранжевых кнопках.
5. Кнопки hero. Сейчас это полупрозрачные «таблетки» с белым кружком слева, похожие на радиокнопки.
