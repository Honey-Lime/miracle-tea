# Продакшн-настройки SEO

Основным адресом сайта должен быть `https://www.чудочай.рф` (`https://www.xn--80ahqsxxd.xn--p1ai`).
Сейчас доступны оба варианта адреса — с `www` и без него. Это создаёт дубли страниц, поэтому на веб-сервере нужен постоянный HTTP 301-редирект с варианта без `www`.

Пример для Nginx (сертификат для домена без `www` тоже должен быть подключён):

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name xn--80ahqsxxd.xn--p1ai;
    return 301 https://www.xn--80ahqsxxd.xn--p1ai$request_uri;
}
```

После развёртывания проверьте:

1. `https://www.чудочай.рф/robots.txt` отдаёт текстовый файл.
2. `https://www.чудочай.рф/api/sitemap.xml` отдаёт XML со всеми товарами.
3. Любой адрес из карты сайта открывает приложение, например `/tea/da-hun-pao-<id>`.
4. В Яндекс Вебмастере и Google Search Console добавлены обе версии домена, но основной задан вариант с `www`; в оба сервиса отправлена карта сайта.
